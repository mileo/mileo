## Luis Felipe Miléo

I build and maintain open source fiscal localizations for Odoo, mostly for Brazil and its neighbors. Partner at [KMEE](https://kmee.com.br/?utm_source=github&utm_medium=referral&utm_campaign=perfil-mileo), where we have implemented Odoo since 2012.

**Where most of my work goes**

- [OCA/l10n-brazil](https://github.com/OCA/l10n-brazil): the Brazilian localization of Odoo (NF-e, NFS-e, CT-e, SPED, payments). One of its maintainers.
- [OCA/l10n-paraguay](https://github.com/OCA/l10n-paraguay) and [kmee/sifen](https://github.com/kmee/sifen): Paraguay's electronic invoicing (SIFEN) for Odoo and as a Python library.
- [OCA/l10n-argentina](https://github.com/OCA/l10n-argentina) and [kmee/arcalib](https://github.com/kmee/arcalib): Argentina's ARCA web services.
- [erpbrasil](https://github.com/erpbrasil): Python libraries for Brazilian electronic documents, used outside Odoo too.
- [kmee/brbank](https://github.com/kmee/brbank): one API for boleto and Pix across Brazilian banks.
- [kmee/kmee-odoo-addons](https://github.com/kmee/kmee-odoo-addons): modules we incubate before proposing them to the OCA.

**Also interested in**: manufacturing planning (DDMRP, Theory of Constraints), retail and point of sale, and running a company with AI agents in the loop.
